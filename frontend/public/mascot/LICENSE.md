# Juli mascot art: licence

The Juli mascot art in this repository is original work, drawn procedurally as
vector shapes for JULI. It is released under the same MIT License as the rest
of the repository (see `LICENSE` at the repository root).

Copyright (c) 2026 vincepalma-dev

It covers:

- `frontend/public/mascot/sprites/juli-<state>-16f.webp`: 16-frame, 256×256 px
  horizontal sprite strips, played at 12 fps
- `frontend/public/mascot/stills/juli-<state>.png`: one still per state, shown
  when the viewer prefers reduced motion
- `frontend/art/mascot/juli-<state>.svg`: the layered vector sources

States: idle, waiting, done, stopped, error, planner, coder, coder-thinking,
coder-typing, reviewer, tester, docs, discussion and follow-up.
